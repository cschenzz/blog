## 快速入门
进入到arthas目录, 执行`java -jar arthas-boot.jar`启动

命令后加`--help`可以查看命令说明, 如`watch --help`
```bash
# 查看命令帮助
help

# 清空当前屏幕区域
cls

# 打印命令历史
history

# 返回当前的工作目录，和 linux 命令类似
pwd

# 退出当前 Arthas 客户端，其他 Arthas 客户端不受影响
quit

# 查看当前会话的信息
session

# 关闭 Arthas 服务端，所有 Arthas 客户端全部退出
stop

# 输出当前目标 Java 进程所加载的 Arthas 版本号
version
```

## 使用arthas处理线上问题
```bash
# 查看哪个Controller处理了请求
# 在浏览器上进行登录操作，检查最耗时的方法
trace *.DispatcherServlet *

# 可以分步trace，请求最终是被DispatcherServlet#doDispatch()处理了
trace *.FrameworkServlet doService

# 查看返回的结果，得到使用到了那些控制器的方法
watch *.DispatcherServlet getHandler 'returnObj'

# -x表示遍历深度，可以调整来打印具体的参数和结果内容，默认值是 1。
# -x最大值是 4，防止展开结果占用太多内存。用户可以在ognl表达式里指定更具体的 field
watch com.example.api.controller.OrderController * -x 2
```
