## IDEA快捷键及使用
移动代码: ALT + SHIFT + 上或下箭头

复制当前行代码: CTRL + D

删除光标所在行 或 删除选中的行: CTRL + Y

小窗口显示文件结构(File Structure): CTRL + F12(windows版本默认), linux下默认CTRL + 0(建议改成前面win版本)

格式化代码(Reformat Code)/optimize imports: CTRL + ALT + L , CTRL + ALT + O
> Reformat Code(接上): Ctrl + Alt + L(win版本默认), Alt + Shift + L(linux, 建议改成前面win版本)

切换书签: F11

打开@Override及实现小窗口: CTRL + O

打开实现小窗口: CTRL + I

当前文件搜索: CTRL + F, 文件中内容搜索: CTRL + SHIFT + F (搜狗输入法也用到了这快捷键， 需要关闭才能起作用)

递进式选择代码块: CTRL + W

插入自定义动态代码模板: CTRL + J

git环境： ctrl + d查看差异, f4查看源码, f7查看下一个差异

调试时: f7进入调试, f8跳过step over, f9恢复程序Resume Program

重新编译运行: CTRL + F9

移动光标到当前所在代码的花括号开始/结束位置: CTRL + [ , CTRL + ]

## FireFox, Edge, Chrome快捷键
全屏: F11

打开开发者工具: f12

切换标签页: CTRL + Page Up/Down, CTRL + TAB

---------------------------------------------

## win系统快捷键
win+E: 打开文件管理器

win+D: 显示桌面

win+L: 锁定系统

F2: 修改文件名


## debian gnome系统操作
win: 打开任务列表, 程序dock栏, (搜索启动, 切换桌面/程序)

Alt + Tab: 切换已经打开的程序

win+L: 锁定系统
