```bash
# ----------------------
# http-server 是一个轻量级的基于 nodejs 的 http 服务器，它可以使任意一个目录成为服务器的目录
# 先全局安装http-server, npm或者pnpm安装都可以
npm i -g http-server
npm install -g http-server

# 查看是否有全局安装
npm list -g

# 先进入到目录, 执行以下命令将使用3333端口启动http服务
http-server -p 3333

# http-server 也支持目录浏览，默认情况下如果没有 index.html，会显示目录中的文件列表
```


## pnpm 命令使用
```bash
# 安装 pnpm，提升依赖的安装速度
npm config set registry https://registry.npmmirror.com
npm install -g pnpm

# 查看pnpm版本
pnpm --version

# 查看npm命令列表
pnpm help

# 安装依赖
pnpm install

# 运行项目
pnpm run dev

# 管理系统前端打包发布到服务器
npm run build:prod

# ----------------------------
# 创建vue3+typescript项目
pnpm create vite my-vue3-app --template vue-ts

# https://cn.vuejs.org/guide/quick-start.html
# vue官网推荐的创建新项目方式
pnpm create vue@latest
```


## npm for vue命令
```bash
# 查看版本
npm -v

# 查看npm命令列表
npm help

# 查看各个命令的简单用法
npm -l

# 查看npm的配置
npm config list -l

# 在当前目录初始化一个package.json文件
npm init

# 查看包的安装路径
npm root [-g]

# -------------------------------------
# --save自动把模块和版本号添加到dependencies部分
# npm install module-name --save-dev自动把模块和版本号添加到devDependencies部分

# 本地安装vue-router
npm install vue-router@4

# 安装axios, i和install都可以
npm install axios
npm i axios

# npm的包安装分为本地安装（local）、全局安装（global）两种，从敲的命令行来看，差别只是有没有-g而已，比如
# 本地安装
npm install express

# 全局安装
npm install express -g

# 查看本地(当前目录)安装的模块
npm list

# 查看所有全局安装的模块
npm list -g

#查看某个模块的版本号(本地, 全局加参数-g)，可以使用命令如下：
npm list vue-router

# 卸载模块
npm uninstall express

# 卸载后，你可以到 /node_modules/ 目录下查看包是否还存在，或者使用以下命令查看：
npm ls

# 使用以下命令更新模块
npm update express

#搜索模块：
npm search express

# -----------------------------
# 安装依赖(根据package.json配置安装)
npm install

# 强烈建议不要用直接使用 cnpm 安装，会有各种诡异的 bug，可以通过重新指定 registry 来解决 npm 安装速度慢的问题。
# 2024.01.22日, 淘宝原镜像域名(registry.npm.taobao.org)的 HTTPS 证书正式到期。如果想要继续使用，需要将 npm 源切换到新的源(registry.npmmirror.com), 否则会报错
npm install --registry=https://registry.npmmirror.com

# 本地开发 启动项目(会提示package.json中配置的环境)
npm run

# 需要在package.json的scripts项中配置运行环境(dev)
npm run dev

# 打包正式环境
npm run build:prod

#构建打包成功之后，会在根目录生成 dist 文件夹，里面就是构建打包好的文件，通常是 ***.js 、***.css、index.html 等静态文件。
#通常情况下 dist 文件夹的静态文件发布到你的 nginx 或者静态服务器即可
```
